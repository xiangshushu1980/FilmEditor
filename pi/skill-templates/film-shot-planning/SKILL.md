# 镜头与提示词制作

Owner: Sean

先读 [共享运行契约](../film-production/references/runtime.md)。读取完整当前剧本、对白、有序镜头与相关实体；跨镜调度读取 get_current_spatial_plan，模型提示词先加载对应官方规范。叙事连续性方法按需用 `load_film_skill` 的 narrative-control，不能从历史提案复原旧镜头事实。

没有拍摄本时直接调用固定 `shots` 阶段。安排每镜叙事目的、主要动作、构图、运镜和时长，保持完整剧情与原对白。身份、服装、道具归属、动作轴及前镜结束/后镜开始状态要连贯；未知绝对尺寸不冒充确认值。来源、风险和待补事实放在报告，不写成画面指令。

空间规划使用 `spatial` 阶段。读取并验证返回完整稿，questions 与校验问题解决后按授权采用。采用已带全镜提示词的空间稿后不逐镜重跑 prompt。

单镜提示词使用 `prompt` 阶段并指定 shotId。独立视频没有前镜记忆，使用本镜实时绑定和必要开始/结束状态；参考标签由本镜实际图片/视频/音频来源推导，不能继承旧编号。官方字段、顺序、时间线及模式职责以 load_film_skill 返回正文为准。

直接改镜头使用共享契约的修订提案。拆分、重排或增删用独立 patch.shots，报告原/新总时长、对白分配和衔接影响；空 prompt 是待生成草稿。报告缺少字段前用 get_shot_details 重读对应完整 prompt，不凭长上下文印象制造阻塞。

交付已保存镜头安排、提示词/空间稿版本及真实校验结果。检查输入格式不等于检查视频效果，视频生成仅在明确请求下执行。
